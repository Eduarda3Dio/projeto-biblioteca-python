Projeto Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em Python, utilizando conceitos de Programação Orientada a Objetos (POO).

Funcionalidades
Cadastro e gerenciamento de usuários
Cadastro e gerenciamento de livros
Empréstimo e devolução de livros
Gerenciamento da biblioteca
Tratamento de exceções

Estrutura do projeto
projeto_biblioteca/
│
├── entidades/
│   ├── usuario.py
│   ├── biblioteca.py
│   ├── livros.py
│   └── emprestimo.py
│
├── utilitarios/
│   └── exceptions.py
│
├── main.py
├── .gitignore
└── README.md
Como executar

Clone o repositório, acesse a pasta do projeto e execute:

python main.py
Objetivo

Projeto desenvolvido para praticar Python, POO, organização de módulos e tratamento de exceções, simulando o funcionamento básico de um sistema de biblioteca.
